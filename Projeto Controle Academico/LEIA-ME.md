# Aplicação C# - Controle Acadêmico (Tema 05)

1. No MySQL 8, rode, a partir da pasta `SQL`, na ordem: `01_ddl.sql`, `02_carga.sql` (o `03_consultas.sql` e o `04_integridade.sql` são opcionais).
2. Em `Db.cs`, troque `SUA_SENHA` (e o servidor, se não for localhost).
3. `dotnet run` dentro da pasta `CSharp` (Windows, .NET 8) ou abra o `.csproj` no Visual Studio.
4. Menu **Cadastros (CRUD)**: uma tela por tabela (incluir, editar, excluir, exportar para Excel).
   Menu **Consultas e relatórios**: as 10 consultas do E6, com parâmetros editáveis e exportação para Excel.
